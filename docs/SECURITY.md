# 本地接口与凭证边界

- 服务只绑定 127.0.0.1；Host 必须匹配当前端口的 localhost/127.0.0.1；跨站 Origin 拒绝。
- 管理接口和模型接口都要求随机本地 Bearer token。静态页面与健康检查不包含凭证。
- 页面禁用外部脚本和第三方请求；凭证从 fragment 读取后立即清除，保留在当前标签 sessionStorage。
- 凭证文件与 Codex 配置按 0600 写入，独立数据目录 0700。设置 API 只返回账号显示名称、过期时间、模型元数据，不返回 token。
- 上游地址固定为 WorkBuddy 服务；携带凭证的 HTTP 请求拒绝重定向。桌面登录解密调用 WorkBuddy 自身的本机二进制。
- 生成请求最长 5 分钟；请求最大 32MB，模型累计输出最大 32MB；断连会取消上游。
- 上游 HTTP 失败、额度/限流和不完整流不会伪装为成功；没有自动生成重试。
- 不支持的输入类型、工具或会话引用显式报错。推理历史用本机密钥加密传回客户端。
- 首版的凭证缓存依靠 macOS 用户目录权限保护，未接入 Keychain；具有当前用户文件读取权限的进程能够读取缓存。
- 源码与发布文件使用明确白名单；.private、缓存、日志与用户配置不打包。
